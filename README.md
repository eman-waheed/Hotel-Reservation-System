Hotel Reservation System

Overview
The Hotel Reservation System is a simple menu-driven program designed to manage hotel room bookings. 
It demonstrates the fundamentals of programming and problem-solving by providing basic operations such as booking, canceling, and checking room availability.

Features
- Book a room by selecting a room number
- Cancel a reservation using the room number
- Check available and booked rooms
- Display details of rooms such as capacity, services, and price
- Generate reservation reports
- Prevents duplicate bookings

How It Works
- The system displays a numbered menu of available operations
- Users select options to book, cancel, or check room details
- A list keeps track of which rooms are available and which are reserved
- Error handling ensures users cannot double-book the same room
